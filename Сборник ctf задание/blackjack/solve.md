# 21 Blackjack

## Overview

**Категория:** MISC  
**Сложность:** Easy

Нам дают питоновый скрипт "лотерейного магазина". Игрок начинает со 100 монет, может делать ставки, угадывая число, и при накоплении 1000 монет может «купить» флаг. Флаг берётся из переменной окружения `FLAG`. Основная цель — разобраться в логике игры и найти способ гарантированно получить флаг, не полагаясь на удачу.

---

## Анализ

### Разведка

Что даётся в условии:

- Исходник Python-скрипта (игра):
    - меню с пунктами:        
        - `1) Play a round (bet & guess)`
        - `2) Buy the flag`
        - `3) Check coins`
        - `4) Quit`
    - стартовый баланс: `START_COINS = 100.0`
    - цена флага: `FLAG_PRICE = 1000`
- Флаг: берётся через `os.getenv("FLAG", "FLAG{default_flag_value}")`
- Вывод при покупке флага:
```python
def flagforyou():
    print(f"\n*** Here is your flag: {FLAG} ***\n")
```

Первичный осмотр:
- Ввод ставки и числа для угадывания.
- Генерация случайного `winning = random.randint(0, 1_000_000)`.
- При угадывании — выигрыш, при неверном ответе — проигрыш.
- Проверяется только условие `bet > coins`, но **не проверяется знак ставки**.

### Детальный анализ

Ключевая часть кода:

```python
bet = float(input("Enter your bet amount: ").strip())

if bet > coins:
    print(f"Invalid bet. BET: {bet} > COINS: {coins}\n")
    continue
```

Здесь видно:
- Разрешается **любое** число с плавающей точкой.
- Проверяется только, что ставка **не больше** текущего количества монет.
- **Отрицательные ставки не запрещены.**

Дальше логика раунда:

```python
try:
    guess = int(input("Enter your guess number: ").strip())
except ValueError:
    print("Invalid guess. Please enter an integer.\n")
    continue

winning = random.randint(0, 1_000_000)

if guess == winning:
    coins += bet * 2
    print(f"🎉 You guessed it! You win {bet * 2} coins!")
    print(f"New balance: {coins}\n")
else:
    coins -= bet
    print(f"❌ Wrong guess! The winning number was {winning}.")
    print(f"You lose {bet} coins. New balance: {coins}\n")
```

Разберём математику:

#### Случай с **положительной** ставкой
- При проигрыше: `coins -= bet` → баланс уменьшается, всё логично.
- При выигрыше: `coins += bet * 2` → баланс увеличивается.
#### Случай с **отрицательной** ставкой

Пусть:
- `coins = 100`
- `bet = -1000`

1. **Проигрыш** (почти всегда, вероятность угадать 1 из 1 000 001):
```python
coins -= bet
# coins = 100 - (-1000) = 1100
```
    - Мы «проиграли» раунд, но:
        - Баланс вырос с 100 до 1100.
        - То есть «проигрыш» нам выгоден.
2. **Выигрыш** (редко):
```python
coins += bet * 2
# coins = 100 + (-1000)*2 = 100 - 2000 = -1900
```
    - Баланс становится отрицательным.
    - Но игра это никак не запрещает — можем продолжать дальше.

Значит, основная уязвимость — **логическая ошибка обработки отрицательных ставок**:
- При проигрыше отрицательной ставки баланс **увеличивается** вместо уменьшения.
- Нам не нужно выигрывать — нам выгодно **проигрывать** раунд с отрицательной ставкой.

После того как монет станет ≥ 1000, можно просто выбрать опцию покупки флага:

```python
elif choice == "2":
    if coins >= FLAG_PRICE:
        coins -= FLAG_PRICE
        flagforyou()
        sys.exit(0)
    else:
        print(f"Not enough coins. You have {coins}, need {FLAG_PRICE}.\n")
```

## Решение

### Подход

Идея:
1. Используем разрешение **отрицательных ставок**.
2. Делаем ставку, которая по абсолютному значению больше стартового баланса (например, `-1000`).
3. С высокой вероятностью раунд мы **проигрываем**, но логика `coins -= bet` приводит к увеличению баланса.
4. После одного такого «проигрыша» наш баланс ≥ 1000.
5. Покупаем флаг через пункт меню `2`.
### Эксплойт / Скрипт

Можно решить задачу вручную, но для автоматизации можно написать скрипт, который взаимодействует с программой, например, через `subprocess` или `pwntools`. Ниже простой пример на `pwntools`:

```python
from pwn import *

# Запускаем локально бинарь
p = process(["python3", "lottery.py"])

# Читаем баннер/меню до приглашения
p.recvuntil(b"> ")

# 1) Идем играть в раунд
p.sendline(b"1")
p.recvuntil(b"Enter your bet amount:")

# Ставим отрицательную ставку
p.sendline(b"-1000")
p.recvuntil(b"Enter your guess number:")

# Вводим любое число (вероятность угадать ~0)
p.sendline(b"0")

# Читаем результат раунда до следующего меню
p.recvuntil(b"> ")

# 2) Теперь покупаем флаг
p.sendline(b"2")

# Читаем вывод с флагом
print(p.recvall().decode())
```

> Важно: имя файла (`lottery.py`) и точный вывод могут отличаться в зависимости от реального задания, но логика взаимодействия остаётся той же.

### Шаги выполнения
1. Запустить программу.
2. В меню выбрать:
```text
1
```
3. Ввести отрицательную ставку (например):
```text
-1000
```
4. Ввести любое число для угадывания (например):
```text
0
```
5. После этого баланс станет ≥ 1000 монет (если раунд проигран, что почти гарантированно).
6. Вернуться в меню и выбрать:
```text
2
```
7. Программа выведет строку вида:
```text
*** Here is your flag: FLAG{...} ***
```

На этом задача решена: флаг получен за счёт логической ошибки обработки отрицательных ставок.
